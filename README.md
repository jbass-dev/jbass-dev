# Hi, I'm John Bass 👋

### Frontend / Full-Stack Software Engineer

I build and deploy full-stack web applications end to end — from React and Next.js frontends to Node.js backends, databases, APIs, and AI-powered features. I enjoy turning ideas into polished, functional products and solving the engineering problems that come with building them.

My work spans **AI applications, SaaS products, real-time data, media generation, authentication, payments, REST APIs, databases, and production deployments.**

## 🚀 Featured Projects

### 🎬 [StoryForge](https://story-forge-tau-three.vercel.app)

A full-stack AI media-generation platform that turns a one-line story concept into a complete vertical video reel. StoryForge orchestrates AI-generated scripts, comic-style scene artwork, narration, and FFmpeg video assembly into a downloadable finished video.

**Tech:** Next.js · TypeScript · Node.js · PostgreSQL · Groq/Llama · FFmpeg · Cloudflare R2

---

### 🤖 [CRM AI](https://independent-perfection-production-c08c.up.railway.app)

A full-stack CRM application with customer and contact management, role-based access control, and AI-assisted workflows. Includes meeting summarization, follow-up email generation, and a customer Q&A chatbot integrated directly into the application.

**Tech:** Next.js · Node.js · Express.js · Prisma · PostgreSQL · OpenAI API

---

### 📌 [OfferBound](https://offerbound.vercel.app)

A full-stack job application platform that tracks the complete search pipeline from **Saved → Applied → Interviewing → Offer**. Includes live dashboard statistics, smart follow-up reminders, authentication, and an AI-powered ATS analyzer that compares resumes against job descriptions and generates targeted rewrites and bullet suggestions.

**Tech:** React · Vite · Firebase · Firestore · Google Auth · Groq AI

---

### 🧴 [Skinstric AI — Frontend Development Internship](https://skinstric-internship1.vercel.app)

An AI skin-analysis application built from a pixel-perfect Figma specification during a frontend development internship. Implemented responsive React interfaces, live selfie capture using `getUserMedia`, base64 image processing, REST API integration, and an interactive demographics dashboard.

**Tech:** React · Vite · REST APIs · getUserMedia · Responsive CSS

---

### 📚 [Summarist](https://summarist-vert.vercel.app)

A subscription-based reading platform featuring authentication, personalized content, state management, and payment processing.

**Tech:** Next.js · TypeScript · Redux · Firebase · Stripe

---

### 🤖 [Nimbus — AI Chat Interface](https://deep-seek-clone-wine.vercel.app)

A multi-model AI chat application with live token streaming, built using the Next.js App Router and OpenRouter API. Designed to provide a responsive conversational interface while handling streamed model responses.

**Tech:** Next.js · React · Tailwind CSS · OpenRouter API · Streaming

---

### 🎬 [CineGalaxy](https://imdb-clone-one-theta.vercel.app)

**Tech:** Next.js · TypeScript · Tailwind CSS

### 🖼 [NFT Marketplace](https://john-internship-sj1k.vercel.app)
